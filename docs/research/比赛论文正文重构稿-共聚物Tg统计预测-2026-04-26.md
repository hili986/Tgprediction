## Abstract

共聚物玻璃化转变温度（glass transition temperature, Tg）预测的难点不在于缺少一个回归算法，而在于缺少一条能够同时处理端点物理约束、真实共聚物小样本、虚拟数据偏差和 DNA 相关跨域外推的完整统计建模链条。现有 Tg 预测研究多围绕均聚物展开，而共聚物 Tg 同时受端点均聚物 Tg、组成比例、链段架构、相容性、相态行为和实验噪声影响；核酸/碱基功能化共聚物还引入氢键、碱基堆积和碱基族偏差，使预测任务进一步偏离常规聚合物分布。

本文提出一个从均聚物源模型到共聚物虚拟增强、真实数据校正和 DNA 相关跨域验证的统计预测框架。该框架首先构建 BestTg 均聚物源模型，使用 PHY-C-light 58 维物理特征、GNN embedding 64 维结构表示和 polyBERT PCA 64 维预训练表示组成 186 维特征，并以 TabPFNRegressor 学习均聚物结构-Tg 映射。随后，该源模型被用于端点 Tg 估计和虚拟共聚物弱标签生成；虚拟样本由端点库或用户输入 recipe 产生，标签来自端点 Tg、Fox 方程、端点 Tg window、descriptor/embedding 混合和 random/block 架构近似，而非实验真值。最后，本文在 7486 条均聚物、149 条清洗后 PolyInfo 一般共聚物和 17 条核酸/碱基功能化共聚物上建立物理先验门控残差回归模型，并以三任务 min-R2 作为主评价指标。

严格评估显示，当前最佳单一回归模型 exp56 在均聚物 random holdout、PolyInfo group holdout 和核酸 group holdout 上的 R2 分别为 0.887、0.849 和 0.817，主指标 min-R2 为 0.817。虚拟数据实验表明，结构近邻虚拟样本可将核酸任务 R2 提升至 0.858，但会使 PolyInfo group R2 降至 0.827；teacher-consistency 过滤能够缓解真实共聚物退化，但核酸增益随之减弱。本文进一步构建证据自适应路由模型，将均聚物预测、未知共聚物外推、已知体系残差插值、多元/嵌段近似、核酸端点路线和端点缺失 fallback 统一到一个可审计预测入口中。结果表明，可信的共聚物 Tg 预测应同时包含严格统计模型和证据自适应应用系统；虚拟数据增强有价值，但只有在端点物理一致性和真实分布相似性约束下才可能转化为稳健泛化增益。

**关键词**：共聚物；玻璃化转变温度；统计预测；虚拟数据增强；物理先验；DNA 相关高分子

## Introduction

玻璃化转变温度 Tg 是高分子材料热性能设计的核心指标。Tg 决定材料从玻璃态向高弹态转变的温度范围，直接影响耐热性、力学稳定性、加工窗口和服役边界。对新型高分子材料而言，若能在合成和表征前预测 Tg，就可以降低实验筛选成本，并加速耐热材料、柔性材料和功能高分子设计。

均聚物 Tg 预测已经成为聚合物信息学中的典型结构-性能回归任务。近年来，分子描述符、图神经网络、预训练聚合物语言模型和小样本机器学习方法被用于从 repeat-unit 结构预测 Tg。这类方法的基本假设是：一个聚合物样本可以由一个主要重复单元表示，模型学习该重复单元与实验 Tg 之间的映射。该假设在均聚物场景中相对合理，但在共聚物场景中不再充分。

共聚物 Tg 预测比均聚物预测更复杂，因为它不是简单的“多输入均聚物预测”。共聚物通常由两个或多个端点结构组成，Tg 同时取决于端点均聚物 Tg、组成比例、随机或嵌段架构、链段相容性、结晶倾向、相分离和实验条件。Fox 方程提供了端点 Tg 和组成比例之间的经典物理近似，但其本身无法表达非理想相互作用；纯机器学习模型能够学习非线性残差，却容易在真实共聚物样本很少时被均聚物大样本分布主导。因此，共聚物 Tg 预测需要同时利用物理先验和统计残差学习。

真实共聚物数据质量进一步限制了模型可信度。公开数据库中的共聚物记录往往存在端点结构缺失、组成比例方向不清、mol% 与 weight fraction 混用、同一体系同一组成下 Tg 冲突、端点均聚物行泄漏和样本标识不唯一等问题。如果不进行数据清洗和 group holdout，随机划分得到的结果很可能只是同一体系内部插值，而不是对新共聚物体系的真实外推。

核酸/碱基功能化共聚物使这一问题进一步跨域化。高分子-DNA 共聚物作为一类新兴的杂化分子，融合了生物大分子的精准识别能力与合成高分子的多功能性，在生物识别、可编程自组装、响应性材料和生物医用材料中具有潜在价值。与此同时，核酸碱基可以引入强氢键、π-π 堆积和碱基特异性相互作用，使链段运动和自由体积偏离普通聚合物规律；核酸相关 Tg 实验数据又极少，无法独立训练大规模模型。本文将 17 条核酸/碱基功能化共聚物作为 DNA 相关材料的先导跨域验证集，目标不是宣称覆盖完整 DNA 长链材料，而是检验共聚物 Tg 模型能否在强相互作用、小样本和碱基族外推条件下保持可解释预测能力。

本文的核心思想是将共聚物 Tg 预测组织成一条完整证据链，而不是一个孤立回归器。首先，均聚物 BestTg 模型提供端点 Tg 估计能力；其次，端点 Tg、Fox 方程和链物理规则生成虚拟共聚物弱标签；再次，PolyInfo 真实共聚物数据经过解析、端点映射和冲突过滤后用于 group holdout；然后，核酸/碱基功能化数据用于 DNA 相关跨域测试；最后，单一回归模型用于严格评估，统一路由系统用于实际预测应用。

本文贡献如下。第一，建立了一个覆盖均聚物、真实一般共聚物、核酸相关共聚物和虚拟共聚物弱标签的 Tg 建模体系。第二，提出物理先验门控残差回归模型，将 Fox 先验、端点 Tg、组成统计量和模型相对 Fox 偏移统一到单一回归路径中。第三，设计三任务 min-R2 指标，避免均聚物大样本掩盖共聚物和核酸任务。第四，系统检验虚拟数据增强的收益与风险，证明虚拟样本可增强核酸任务但也可能损害真实共聚物泛化。第五，构建证据自适应路由模型，将严格统计模型转化为可用于不同输入证据条件的预测系统。

## Results and discussion

### A homopolymer source model provides endpoint Tg estimates for copolymer prediction

本研究首先建立均聚物 Tg 源模型，因为共聚物预测需要端点 Tg 作为物理先验。该源模型不是单一描述符回归，而是融合三类聚合物表示：PHY-C-light 58 维物理化学特征用于表达链段刚性、局部结构和基本物性；GNN embedding 64 维用于表达重复单元图结构；polyBERT PCA 64 维用于吸收预训练聚合物语言模型中的序列表示。三类特征合计 186 维，输入 TabPFNRegressor 形成 BestTg 均聚物预测器。

BestTg 源模型承担两个功能。第一，它直接服务于均聚物 Tg 预测，在统一路由测试的严格 train/test split 中达到约 R2=0.907、MAE=20.60 K；在后续统一单一回归体系中，因模型同时兼顾共聚物和核酸任务，均聚物 holdout R2 稳定在 0.887。第二，它作为共聚物端点 Tg 估计器，为 Fox 方程和端点物理特征提供输入。这个定位很重要：本文不是把均聚物模型直接当作共聚物模型，而是把均聚物模型作为端点物理先验的来源。

为支持大量共聚物组合，BestTg 被封装为 `BestTgPredictor`。该对象包含模型加载、PCA/预处理器、TabPFN 回归器、端点 featurization 和组件级缓存。对于虚拟共聚物生成，同一端点结构会在多个组成比例、多个二元/多元组合和 random/block 架构下重复出现；因此，`featurize_component()` 会缓存端点 SMILES 的 RDKit/物理特征、GNN embedding 和 polyBERT 表示，使同一端点在一个任务中只计算一次。这个设计将计算单元从“每条 recipe 重算”改为“每个端点复用”，是后续大规模虚拟生成可行的基础。

### Virtual copolymer data are generated from endpoint predictions and physical rules, not from experiments

虚拟数据生成是本文“从虚拟数据增强”部分的源头。生成脚本 `generate_virtual_copolymer_dataset.py` 是专用长任务入口，而不是对单条预测命令的外部循环。它支持 `auto`、`csv` 和 `hybrid` 三种模式：`auto` 从内部端点库枚举候选组合，当前主要使用 Bicerano/7k 去重均聚物相关端点；`csv` 读取用户指定 recipe；`hybrid` 合并内部候选和用户候选。生成对象覆盖二元和多元共聚物，架构标签支持 `random`、`block` 和 `both`。

每个虚拟 recipe 的 Tg 标签由端点预测和物理规则共同产生。脚本首先获得每个端点的均聚物 Tg：若端点命中 7k 去重数据库或预计算表，则优先复用已有结果；若没有命中，则调用 BestTg 源模型预测端点 Tg。随后，脚本根据组成权重计算 Fox reference、端点 Tg window、线性混合和 descriptor/embedding 加权混合，并由 `BestTgPredictor.predict_multicomponent()` 给出 random 或 block 架构下的多组分近似 Tg。由此得到的 Tg 是低保真弱标签，不是实验真值。

虚拟数据输出被设计为可审计表，而不是只包含一个 Tg 数字。每行记录稳定 `recipe_id`、生成模式、架构、组分数、端点 SMILES 序列、归一化权重、预测 Tg、primary method、descriptor-mix Tg、Fox reference Tg 和端点 Tg window。稳定 ID 支持 resume 和去重；Fox reference 和端点 window 支持后续物理一致性筛选；primary method 支持区分标签来自端点复用、BestTg 预测或多组分近似。

生成器还解决了早期虚拟数据生成中的核心工程瓶颈。最初如果逐条调用预测脚本，每个样本都会启动新 Python 进程、重复加载 TabPFN、重复拟合 PCA/预处理器、重复加载 polyBERT 和 GNN checkpoint，导致几百条数据就需要很长时间。新生成器在一个任务中只创建一个 `BestTgPredictor` 实例，`predictor.fit()` 只执行一次，所有 recipe 共享模型对象和端点缓存；结果按 chunk 增量写入，并通过 `--resume` 跳过已完成 recipe。这一改造使虚拟数据生成从“低效脚本调用”转为可恢复、可复现、可长时间运行的数据工程流程。

### Cleaning real copolymer data is necessary before model evaluation

真实共聚物数据来自 PolyInfo 相关原始记录，但原始记录不能直接用于建模。数据中存在复制粘贴格式不统一、端点结构映射缺失、组成比例方向不明确、mol% 和 weight fraction 混用、样本 ID 不唯一、pure endpoint rows 泄漏以及同一体系同一组成下 Tg 冲突等问题。若直接随机划分训练和测试，模型可能学习到重复体系内部信息，而不是获得新体系外推能力。

本文通过专用解析和冲突过滤流程构建清洗数据。`parse_polyinfo_raw.py` 从原始复制粘贴内容中抽取共聚物体系、端点、组成和 Tg；端点映射流程将共聚物组分关联到均聚物端点库；比例方向审计确定 `w1_used` 对应的实际组分；mol% 行在可接受条件下近似转换为 weight fraction；pure endpoint rows 被剔除以避免端点泄漏。由于原始 `sample_id` 可能出现 `polyinfo:nan` 等非唯一标识，项目还构造稳定行标识用于诊断和预测结果回连。

冲突过滤进一步提高了真实数据可靠性。默认规则是：同一 `COID + w1_used` 下，如果 Tg 标准差超过 10 K，则将该组视为冲突组并整体剔除。例如，P900016 EVA 和 P900017 EVOH 中存在同一组成下 Tg 跨度很大的记录，这类样本会显著限制模型上限。冲突过滤后，数据从原始共聚物记录中剔除 11 行高冲突样本，形成更适合 group holdout 的 clean 数据。该过程体现了统计预测中的一个关键事实：对小样本共聚物而言，数据清洗本身就是模型性能的一部分。

### A single physics-guided regressor balances homopolymer, copolymer and nucleobase tasks

在真实数据基础上，本文训练统一单一回归模型，而不是为三个任务分别训练完全独立模型。最终训练表包含 7486 条均聚物真实数据、149 条清洗后 PolyInfo 一般共聚物数据和 17 条核酸/碱基功能化共聚物数据。为避免均聚物样本量主导训练目标，样本权重设置为均聚物 1、一般共聚物 10、核酸相关共聚物 60。虚拟样本不被无条件加入最终模型，而是单独用于增强实验。

模型结构为物理先验门控残差回归。首先，端点 Tg、Fox Tg、端点 Tg 最大值/最小值/加权均值和端点跨度形成共聚物物理先验；其次，结构 embedding 和组成统计量提供数据驱动残差信息；最后，非均聚物门控校准、低 Fox 区域残差收缩和 `base_prediction - endpoint_tg_fox` 差值校准控制模型相对物理先验的偏离。该设计的目的不是最大化模型自由度，而是在真实共聚物小样本条件下限制不可靠残差。

当前最佳合规模型为 `exp56_homo_local_fox_pred_delta_nonhomo_cal_lowfox_shrink_nopure`。严格评估结果显示，该模型在均聚物 random holdout 上 R2=0.887、MAE=27.164 ℃；在 PolyInfo group holdout 上 R2=0.849、MAE=16.654 ℃；在核酸/碱基功能化 group holdout 上 R2=0.817、MAE=6.266 ℃。主指标 min-R2 为 0.817。该结果低于“所有任务 R2=0.95”的理想目标，但它是在避免 pure endpoint 泄漏、使用 group holdout、同时覆盖小样本核酸跨域任务下得到的当前最可信结果。

消融实验说明模型提升来自受约束的物理校准。exp45 是无 pure endpoint 泄漏的基础物理-局部残差模型，min-R2 为 0.789；exp53 加入非均聚物门控 endpoint/Fox 校准，将 min-R2 提升至 0.792；exp55 加入低 Fox 区域向端点物理收缩，将 min-R2 提升至 0.810；exp56 加入非均聚物预测差值校准，将核酸 group R2 提升至 0.817，并成为当前最佳模型。虽然 exp56 相比 exp55 使 PolyInfo group R2 从 0.852 略降至 0.849，但它提高了最弱的核酸任务，因此在 min-R2 目标下更均衡。

### Virtual augmentation improves nucleobase transfer but can damage real copolymer generalization

虚拟数据实验揭示了增强收益和真实分布偏移之间的冲突。exp57 从已有 5000 条 HYBRID-HOMO186 虚拟行中选择与真实 PolyInfo 样本在非目标特征空间较接近的 400 条，并以 0.05 的低权重加入训练。结果显示，核酸 group R2 从 exp56 的 0.817 提升至 0.858，说明虚拟共聚物弱标签确实包含对核酸跨域有用的结构或高 Tg 信号。

然而，exp57 同时使 PolyInfo group R2 从 0.849 降至 0.827。该退化说明，结构近邻并不能保证虚拟标签与真实共聚物物理规律一致。由于本文目标是同时覆盖一般共聚物和核酸相关共聚物，真实 PolyInfo group holdout 的明显下降不可接受。因此，exp57 不能作为最终模型，只能作为虚拟数据具有跨域潜力的证据。

exp58 使用 teacher-consistency 进一步过滤虚拟样本。具体做法是先用真实数据路径训练教师模型，再保留虚拟标签与教师预测差异不超过 30 ℃ 的样本。筛选前，虚拟标签与教师预测的中位差异约为 145.05 ℃；筛选后，中位差异降至约 12.65 ℃，说明现有虚拟池中存在严重标签冲突，而 teacher-consistency 可以显著提高一致性。

但 exp58 仍未超过 exp56 的主指标。它将 PolyInfo group R2 恢复到 0.850 左右，却使核酸 group R2 回落至 0.817。这说明强一致性过滤可能同时过滤掉对核酸跨域有用的高 Tg 信号。由此可得出本文对虚拟数据增强的主要结论：虚拟样本不是越多越好；关键不是样本量，而是端点 Tg 完整性、Fox 物理一致性、教师一致性和真实分布相似性之间的平衡。

### Error diagnostics show that remaining failures are data- and representation-limited

误差诊断显示，当前模型瓶颈不是简单调参可以解决。PolyInfo group holdout 中，P900015 是主要硬体系。早期 exp45 诊断显示，P900015 的 MAE 约 45.12 ℃，剔除该体系可将计算得到的 PolyInfo group R2 从约 0.844 提高到约 0.895。后续 exp53 诊断仍显示 P900015 主导误差，并且 endpoint Fox prior 在 P900015 和 P900025 上反而比模型预测更接近实验值，说明学习残差有时会将预测从有用物理先验推开。

P900015 的错误不是单一测量冲突或比例方向错误能够解释的。诊断显示，该体系同时存在低 Tg/高次要组分比例行被过预测和高 Tg/低次要组分比例行被低预测的混合符号误差，因此简单系统级截距校正不安全。更合理的解释是当前特征没有显式表达相态、混溶性、结晶和组成-相行为，这些因素在部分共聚物体系中可能比端点 Tg 和组成比例更关键。

核酸任务也存在系统性偏差。exp55 之后，T 族样本仍被系统性低估，G 族样本仍被系统性高估。诊断性 leave-base-out 校准表明，如果只在核酸任务内部使用 endpoint/Fox affine calibrator，R2 可以明显提高；但这种做法属于核酸任务特定后处理，不能证明对一般共聚物和均聚物同时泛化。因此，本文仅将其作为诊断和应用上界，不作为最终主模型。

exp56 之后的多轮实验进一步确认当前瓶颈来自数据和表示，而不是小幅超参数。final-calibration lambda 变化几乎只是数值噪声；source-balanced 或 nucleobase-boosted final calibration 最多带来约 0.00022 的 min-R2 改变，并会降低 PolyInfo group R2；低权重 additive physical/embedding sum-kernel 将主指标降至 0.815844；现有虚拟行的结构近邻和 teacher-consistency 筛选也未带来合规提升。后续提高模型上限应优先重建端点完整虚拟数据、加入 no-leak phase/reliability 特征和扩充核酸实测数据。

### An evidence-adaptive routing model turns the statistical framework into a usable predictor

严格单一回归模型用于论文主结果，但实际预测还需要处理输入证据不完整的问题。为此，本文构建证据自适应路由模型 `predict_polymer_tg_universal.py`。路由模型不是另一个单纯回归器，而是一个任务分发系统：它先识别输入类型，再根据端点 Tg、体系 ID、架构、核酸标记和 fallback 许可选择预测路线，并在输出中记录路线和证据来源。

路由模型的第一步是任务识别。若输入只有单一 `smiles`，系统判定为均聚物并调用 BestTg/186d TabPFN；若输入包含 `smiles1, smiles2, w1`，系统判定为二元共聚物；若存在多个 `smiles_i, w_i`，系统判定为多元共聚物；若 `architecture=block`，系统进入 block proxy；若提供 `system_id` 或 `COID`，系统尝试匹配 clean PolyInfo calibration 表；若输入为核酸相关体系，系统检查实际端点 Tg 是否可用。

路由模型的第二步是路线选择。未知二元 random 共聚物在端点 Tg 可用时进入 Global Linear-Fox 或 endpoint/Fox 残差路线；已知 PolyInfo 体系进入 `binary_known_system_local_residual_idw`，在全局 Linear-Fox 基线之外使用同体系组成点做 residual IDW 修正；多元 random 共聚物采用 endpoint Fox 多组分近似；block 共聚物输出 miscible proxy 和 Tg window，不假装精确处理相分离；端点缺失时可选择 BestTg weighted descriptor/embedding fallback，并降低置信度；核酸端点已知时可进入 actual endpoint Linear-Fox 或 Physics-Ridge 应用路线。

路由模型的第三步是输出可审计结果。输出不只包含 Tg 预测值，还包含 `router_route`、`primary_method`、端点 Tg、Fox reference、是否命中 known system、是否使用 BestTg fallback、架构类型和风险提示。这个设计使每个预测都能被解释为“严格外推”“已知体系插值”“核酸端点校准”或“端点缺失 fallback”。因此，路由模型是本文工作量的重要组成部分：它把研究模型转化为面向实际材料筛选的预测系统，同时避免把应用插值指标混入严格 group holdout 主结果。

## Methods

### Data sources and preprocessing

真实数据包括 7486 条均聚物 Tg 数据、149 条清洗后 PolyInfo 一般共聚物数据和 17 条核酸/碱基功能化共聚物数据。均聚物数据用于训练 BestTg 源模型和统一回归模型；PolyInfo 数据用于一般共聚物 group holdout；核酸数据用于 DNA 相关跨域验证。虚拟共聚物数据由生成脚本产生，只作为弱监督增强和风险诊断，不作为实验真值。

PolyInfo 数据通过解析、端点映射、比例方向判定、单位统一、pure endpoint row 剔除、稳定行 ID 构造和冲突过滤进行清洗。冲突过滤规则为同一 `COID + w1_used` 下 Tg 标准差超过 10 K 的组整体剔除。核酸数据按碱基族进行 group holdout，以避免同一碱基族信息泄漏。

### Homopolymer source model

BestTg 源模型输入 repeat-unit SMILES，输出均聚物 Tg。特征由 PHY-C-light 58 维、GNN embedding 64 维和 polyBERT PCA 64 维组成。训练评估时，PCA 和回归器只在训练折拟合；用于端点预测和虚拟生成时，可在全量均聚物数据上拟合以获得最佳端点估计。模型实现为 `BestTgPredictor`，并使用 `_component_cache` 复用端点 featurization 结果。

### Virtual copolymer generation

虚拟生成脚本支持 `auto`、`csv` 和 `hybrid` 模式，支持二元、多元、random、block 和 both 架构。每个 recipe 包含端点 SMILES、组成权重和架构标签。端点 Tg 优先来自去重数据库或预计算表；缺失时由 BestTg 源模型预测。Fox reference 使用 Kelvin 温度计算：

```text
1 / Tg_Fox = sum_i w_i / Tg_i
```

生成结果包含 `recipe_id`、`mode`、`architecture`、`n_components`、`components_serialized`、`weights_serialized`、`tg_k_pred`、`tg_c_pred`、`primary_method`、`descriptor_mix_tg_c`、`fox_reference_tg_c` 和 `component_tg_window` 等字段。脚本按 chunk 增量写入，并通过稳定 recipe ID 支持断点续跑。

### Physics-guided gated residual regression

统一模型使用结构、组成、端点物理和校准特征。结构特征来自 repeat-unit 表示和 embedding；组成特征包括组分权重、最大/最小比例、组成熵和 Herfindahl 指数；端点物理特征包括端点 Tg 最小值、最大值、加权均值、Fox Tg 和端点跨度；校准特征包括 `is_homopolymer`、`endpoint_tg_fox_c`、低 Fox 标记和 `base_prediction - endpoint_tg_fox`。

训练表为：

```text
D_real = D_homopolymer + D_polyinfo + D_nucleobase
```

样本权重为均聚物 1、一般共聚物 10、核酸相关共聚物 60。模型包含三类校准：非均聚物门控 endpoint/Fox 校准、低 Fox 区域残差收缩、非均聚物预测差值校准。最终输出 Tg 摄氏度预测。

### Evaluation protocol

均聚物任务使用 random holdout；一般共聚物任务使用 PolyInfo group holdout，按体系外推；核酸任务使用 group holdout 或 leave-base-out，按碱基族外推。主指标为：

```text
primary min-R2 = min(R2_homopolymer, R2_polyinfo_group, R2_nucleobase_group)
```

报告指标包括 R2、MAE 和 RMSE。虚拟数据实验必须同时报告 PolyInfo group R2 和核酸 group R2；若真实 PolyInfo group holdout 明显退化，则不提升为最终模型。

### Evidence-adaptive routing

路由模型 `predict_polymer_tg_universal.py` 根据输入证据选择路线。输入为单一 SMILES 时调用 BestTg；输入为二元共聚物时检查端点和体系 ID；输入为多元或 block 架构时进入相应端点物理近似；已知体系可用 residual IDW；核酸端点已知时可用 actual endpoint 物理路线；端点缺失时可使用 BestTg weighted descriptor/embedding fallback 并标注低置信度。输出保留预测路线、主方法、端点物理量和风险提示。
