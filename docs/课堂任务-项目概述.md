# 人工智能辅助高分子材料玻璃化转变温度的多尺度预测

## 一、课题题目与研究方向

**课题名称**：基于物理因果链驱动的多尺度机器学习方法预测高分子材料玻璃化转变温度

**研究方向**：以高分子物理理论为指导，构建从原子尺度到聚合物链尺度的多层级特征表示体系，结合先进的表格学习模型，实现对均聚物玻璃化转变温度（Tg）的高精度预测与物理可解释分析。

---

## 二、要解决的问题

玻璃化转变温度（Tg）是高分子材料最重要的热力学参数之一，直接决定了材料的使用温度窗口、加工条件和服役性能。传统的 Tg 测定依赖 DSC/DMA 等实验手段，周期长、成本高，严重制约了新材料的研发效率。

当前 Tg 机器学习预测领域存在三个核心瓶颈：

### 2.1 表示瓶颈：单尺度描述符的物理信息缺失

现有方法普遍采用单一尺度的分子描述符（Morgan 指纹、RDKit 2D 描述符等），仅编码了原子连接拓扑，缺乏对 Tg 物理起因的显式表征。然而 Tg 本质上由**多个尺度的物理因素协同决定**：

- **原子/键尺度**：骨架键的旋转势垒决定链段运动的微观能垒
- **重复单元尺度**：侧基体积、极性、氢键能力影响分子间相互作用强度
- **链段尺度**：链的构象自由度决定玻璃化时被冻结的构象熵大小

单一尺度描述符无法同时捕获这些信息，导致预测精度存在理论天花板（文献报道基于单体描述符的极限约 R²≈0.84）。

### 2.2 评估失真：文献结果的统计可靠性不足

文献中报道的高精度结果往往基于简单的随机划分（如 90/10 split），存在两个严重问题：

- **信息泄漏**：数据集中同一聚合物的不同来源测量值可能分别进入训练集和测试集，造成虚假的高精度
- **统计波动**：当测试集仅有 10-20 个样本时，R² 的置信区间极宽，单次划分的结果不具备统计可靠性

例如，Afsordeh (2024) 报道的 R²=0.97 基于 90/10 划分、仅 12 个测试样本，其统计显著性存疑。领域内缺乏统一、严格的评估标准。

### 2.3 可解释性缺失：黑箱模型难以提供物理洞见

纯数据驱动的黑箱模型即使获得高精度，也无法回答"哪些结构因素如何影响 Tg"这一核心科学问题，限制了模型在材料设计中的实际指导价值。

## 三、拟采用的技术方案

### 3.1 总体思路

以 **Tg 的物理因果链**为主线，自底向上构建多尺度特征金字塔，每一层特征对应明确的物理机制。最终集成为统一的特征向量，输入先进的表格学习模型进行端到端预测。

核心理念：**不是"加什么特征效果好就用什么"，而是"Tg 的物理机制要求我们在每个尺度上编码特定信息"。**

### 3.2 多尺度物理特征金字塔

拟构建五层特征表示，总计约 186 维：

```
┌─────────────────────────────────────────────┐
│  第 5 层：化学统计 (polyBERT PCA 64d)        │  ← 全局化学指纹
├─────────────────────────────────────────────┤
│  第 4 层：聚合物链 (GNN 嵌入 64d)            │  ← 周期性拓扑结构
├─────────────────────────────────────────────┤
│  第 3 层：链段物理 (~10d)                    │  ← 构象自由度
├─────────────────────────────────────────────┤
│  第 2 层：重复单元 (~30d)                    │  ← 基团贡献 + 氢键
├─────────────────────────────────────────────┤
│  第 1 层：原子/键 (~18d)                     │  ← 骨架柔性
└─────────────────────────────────────────────┘
```

各层的物理依据与实现方案：

| 层级 | 物理机制 | 拟构建的特征 | 理论依据 |
|------|---------|------------|---------|
| 原子/键 | 主链柔性决定链段运动能垒 | 修正柔性键比例、骨架旋转势垒代理量 | Schneider-DiMarzio M/f 理论 |
| 重复单元 | 侧基贡献具有加和性 | 基团贡献预测 Tg (GC_Tg)、氢键供/受体描述符 | Van Krevelen 基团贡献法 |
| 链段 | 构象熵冻结驱动玻璃化 | 特征比(curl ratio)、有效自由度比、构象应变 | Gibbs-DiMarzio 构象熵理论 |
| 聚合物链 | 长程拓扑影响堆积效率 | 基于外部大规模数据预训练的 GNN 嵌入 | 图神经网络表示学习 |
| 化学统计 | 化学组成的全局统计特征 | polyBERT 语言模型嵌入经 PCA 降维 | 高分子预训练语言模型 |

**关键设计**：第 1-3 层为**显式物理特征**（可直接解释），第 4-5 层为**隐式学习特征**（补充物理模型未覆盖的高阶模式）。这种"物理先验 + 数据驱动"的混合策略兼顾了可解释性与预测精度。

### 3.3 数据集构建

拟整合多个公开数据源，构建大规模统一 Tg 数据集：

| 数据源 | 预期规模 | 用途 |
|--------|---------|------|
| Bicerano 经典数据集 | ~300 条 | 基准验证 |
| PolyMetriX、NeurIPS OPP 等公开数据 | ~7,000 条 | 主训练集 |
| 合计（去重后） | ~7,500 条 | 统一评估 |

对数据进行严格的预处理：SMILES 规范化 → 去重（同一聚合物多条记录取中位数）→ 异常值过滤。

### 3.4 模型选择与训练策略

拟对比以下模型架构：

- **梯度提升树族**：CatBoost、LightGBM、XGBoost（表格数据传统强基线）
- **集成方法**：Stacking（多模型融合）
- **先验数据拟合网络**：TabPFN v2（基于 Transformer 的零调参表格模型）
- **高斯过程 / Ridge 回归**：作为可解释性参考基线

预处理管线：Yeo-Johnson 幂变换 → MinMaxScaler 归一化 → 特征选择（SHAP 重要性排序）。

### 3.5 严格的评估体系

采用 **Nested Cross-Validation** 消除评估偏差：

```
外层：RepeatedKFold(n_splits=5, n_repeats=3)  → 无偏性能估计
  └─ 内层：KFold(n_splits=3)                   → 超参数选择 / 特征选择
```

- 所有模型选择、特征选择均在内层完成，外层仅用于无偏性能估计
- 报告指标：R²、MAE、RMSE（均含标准差）
- 不确定性量化：拟采用 MAPIE 框架的 CrossConformal 方法，给出 90% 置信区间

### 3.6 可解释性分析

利用 SHAP (SHapley Additive exPlanations) 进行多层次的可解释性分析：

- **全局特征重要性**：哪些物理因素对 Tg 预测贡献最大？
- **消融实验**：逐层移除特征，量化每个尺度的贡献
- **物理一致性验证**：SHAP 给出的特征重要性排序是否与高分子物理理论预期一致？

### 3.7 预期目标

| 指标 | 文献当前水平 | 本项目目标 |
|------|------------|----------|
| R²（Nested CV） | 0.84-0.90 | > 0.91 |
| MAE | 25-35K | < 22K |
| 评估方法 | 简单 train/test split | Nested CV（统计可靠） |
| 可解释性 | 黑箱 | SHAP + 物理因果链验证 |
| 不确定性量化 | 无 | 90% 覆盖率的置信区间 |

## 四、技术路线图

```
Phase A  数据诊断与清洗
   ↓     评估数据集质量，确定 R² 理论天花板
Phase B  尺度 1-2 特征工程（原子/键 + 重复单元）
   ↓     修正柔性键、基团贡献、氢键描述符
Phase C  尺度 3 链段物理特征
   ↓     构象采样、特征比、有效自由度
Phase D  尺度 4-5 预训练嵌入
   ↓     GNN 嵌入 + polyBERT PCA
Phase E  模型集成与消融实验
   ↓     多模型对比、逐层消融、SHAP 分析
Phase F  总结与报告
```

## 五、创新点

1. **物理因果链驱动的特征设计**：区别于"暴力堆叠描述符"的黑箱做法，每一层特征都有明确的物理理论支撑，实现了物理先验知识与数据驱动方法的有机融合。

2. **严格的统计评估体系**：采用 Nested CV 替代简单 split，消除文献中普遍存在的评估失真问题，使结果具备统计可靠性和可复现性。

3. **多尺度 × 多模态特征融合**：首次系统性地将显式物理描述符（修正柔性键、构象熵代理量）与隐式预训练嵌入（GNN、语言模型）在统一框架下融合。
