## 四、两条算法主线

### 4.1 整体路：Universal Single Regressor

**身份**：AGENTS.md 定义的官方研究主线（"Build one universal Tg single-regressor system"）

**入口**：`scripts/train_universal_tg_single_regressor.py`（1052 行）
**核心类**：`PhysicsResidualKernelRegressor`（`src/ml/universal_tg_model.py`，636 行）

**架构（一个回归器对象，一条预测路径）**：
```
ŷ = prior(X)           # weighted ridge on physical/composition columns
  + residual(X)        # RBF-kernel residual on full universal feature
  + final_calibration  # optional: non-homo-gated Fox/endpoint correction
  + final_shrinkage    # optional: low-Fox region shrink toward Fox
  + homo_correction    # optional: homopolymer-specific high-dim residual
```

**特征**：`HYBRID-HOMO186` 1191 维 = M2M-V 基础（含 VPD）+ PHY-C 58d + GNN 64d + polyBERT PCA 64d + 端点 Tg/Fox 列 + 组成统计列

**训练数据**（exp56）：7,652 行 = homopolymer 7,486 + polyinfo 149 + nucleobase 17

**样本权重**：homopolymer 1.0 / copolymer 10.0 / nucleobase 60.0 / virtual 0.0

**评估协议**：
- 均聚物：random holdout (n=1498)
- 一般共聚物：体系级 group holdout (n=149)
- 核酸：碱基族级 group holdout (leave-base-out, n=17)
- 主指标：`min(R²_homo, R²_polyinfo_group, R²_nucleo_group)`

**当前最优 exp56 严格指标**（`exp56_homo_local_fox_pred_delta_nonhomo_cal_lowfox_shrink_nopure`）：

| 任务 | n | R² | MAE/K | RMSE/K |
|---|---:|---:|---:|---:|
| 均聚物 random holdout | 1498 | **0.8871** | 27.16 | 38.09 |
| PolyInfo random holdout | 30 | 0.9296 | 10.66 | 15.45 |
| **PolyInfo group holdout** | 149 | **0.8492** | 16.65 | 21.64 |
| **Nucleobase group holdout** | 17 | **0.8171** | 6.27 | 8.51 |
| **Primary min-R²** | | **0.8171** | | |

### 4.2 自动路由路：Universal Router

**身份**：应用层入口，根据输入证据分发到不同子方法

**入口**：`scripts/predict_polymer_tg_universal.py`（721 行）
**核心类**：`UniversalTgRouter`

**路由规则**：

| 输入特征 | router_route | primary_method |
|---|---|---|
| 单 SMILES | `homopolymer_besttg` | BestTg 186d TabPFN（懒加载） |
| 二元 random + 已知体系（COID 命中） | `binary_known_system_local_residual_idw` | global Linear-Fox + same-system residual IDW (k=3) |
| 二元 random + 未知体系 | `binary_global_linear_fox` | RidgeCV on Fox endpoint Tg → Tg_C |
| 多元 random | endpoint Fox | 1/Tg = Σwᵢ/Tgᵢ |
| Block | Fox miscible proxy + Tg window | Fox + 端点 [min, max] |
| 端点缺失（允许 fallback） | besttg fallback | BestTg weighted descriptor mix |
| 核酸专用（**未接入正式 router**） | nucleobase_known_endpoint（计划） | 实测端点 Linear-Fox / Physics-Ridge |

**测试结果**（`results/universal_router_fulltest/`）：

均聚物（n_test=1498，BestTg+186d，公平 train/test split）：
- R² = **0.9069**, MAE = 20.60 K

PolyInfo（n=149）：

| 协议 | R² | MAE/K | 说明 |

| residual IDW **leave-composition** | 0.9197 | 11.28 | 同体系外推到新组成 |
| production replay（用了 calibration table 的行） | 0.9985 | 0.67 | **泄漏，不可作为论文指标** |

### 4.3 三任务真实数字对照（同协议）

| 任务 | 协议 | 整体路 (exp56) | 路由路（最佳子方法） | 差距 |
|---|---|---:|---:|---:|
| 均聚物 holdout | random train/test split | 0.8871 | **0.9069** (BestTg full fit) | 路由 +0.020 |
| 共聚物**新体系**外推 | leave-system-out | **0.8492** (group) | 0.8205 (Linear-Fox LSO) | **整体 +0.029** |
| 核酸新碱基族 | leave-base-out | 0.8171 | **0.9202** (Linear-Fox LBO, 实测端点) | 路由 +0.103 |

**核心发现（不同任务最优方法不一样）**：
1. **均聚物**：路由略胜，因其用全量数据 fit BestTg；整体路因样本权重压制只有 0.887
2. **共聚物新体系**：**整体路胜出**——这是 single-regressor 真正的卖点，证明 ridge+kernel residual 比 Linear-Fox 学到了非线性体系结构
3. **核酸**：路由完胜——根本原因是 17 条样本 + 4 个实测端点 Tg 让 Linear-Fox 即可达 0.92；整体路的 1191d 特征在 17 条数据上无法发挥

### 4.4 两条路在 AGENTS.md 协议下的合规张力

AGENTS.md L250-267（Model Rules）明确写：
```
Avoid:
- task-specific routing as the main solution
- choosing different external predictors for different material classes
- improving one category by badly degrading another
```

但**当前两条路并存**：
- 整体路是研究主线（论文第 4-5 章主体）
- 路由路是应用主入口（论文第 6 章；阶段成果 2026-04-25 把它当主交付物展示）

**合理化解释**：
- 路由路的子模块（BestTg / Fox / Linear-Fox / Physics-Ridge）都来自整体研究的工程组件
- 路由路输出 `router_route` / `primary_method` / `confidence`，可审计
- AGENTS.md 的 R²≥0.95 目标在整体路下不可达（min-R²=0.817 已 BLOCKED），但在路由路按任务最强方法下，均聚物 0.91 / 核酸 0.97 已接近

## 九、关键决策点（Yellow Zone）

### 决策 1：论文主线方向

候选：

- **A. 整体路为主线 + 路由路为应用补充**（当前重写方案默认）
  - 优势：合规 AGENTS.md 单一回归原则；严格 group holdout 数字（0.887/0.849/0.817）不浮夸
  - 劣势：核酸 0.817 不亮眼；路由内更高的数字（0.92/0.97）浪费

- **B. 路由路为主线 + 子方法物理学解释**
  - 优势：核酸 0.92 / 共聚物已知体系 0.93 / 均聚物 0.91 数字亮眼
  - 劣势：违反 AGENTS.md Model Rule；审稿人可能质疑"是工程拼接不是统计建模"

- **C. 双线并陈**
  - 优势：完整呈现工作量；展示"不同任务最优方法不同"的洞察
  - 劣势：35 页可能不够；故事线复杂

**推荐**：**A + 在第 5 章新增"专用方法在小样本极端任务上的对照"小节**——把路由路核酸 Linear-Fox LBO R²=0.92 作为 single-regressor 0.817 瓶颈的物理解释，与 round 25 报告"瓶颈在数据/表示"结论形成闭环。

### 决策 2：突破整体路瓶颈的工作选择

候选：
- A1：endpoint-aware 虚拟数据重建（耗时但符合 round 25 建议第 1 项）
- A2：核酸数据扩充（需要文献检索 / 实验合作，长期）
- A3：新的共聚物相态特征（需要领域知识，中期）
- A4：放弃突破，固化 exp56 + 接核酸专用进 router（短期收尾）

## 附录 B：远程访问与下载工具用法

### 测试连接
```powershell
$env:TG_REMOTE_PASSWORD = "<密码>"
python scripts/remote_tg_command.py --use-paramiko "pwd && hostname"
```

### 拉单个文件
```powershell
python scripts/remote_tg_fetch.py file `
  results/universal_single_regressor/exp56_*/summary.json `
  results/universal_single_regressor/exp56/summary.json
```

### 拉整个目录（默认排除 *.joblib）
```powershell
python scripts/remote_tg_fetch.py dir `
  results/universal_router_fulltest `
  results/universal_router_fulltest
```

### 自定义排除
```powershell
python scripts/remote_tg_fetch.py dir `
  results/universal_single_regressor/exp56_... `
  results/universal_single_regressor/exp56_... `
  --exclude '*.joblib' --exclude '*.parquet'
```

```powershell
$env:TG_REMOTE_PASSWORD = "<密码>"
powershell -ExecutionPolicy Bypass -File scripts/codex_universal_tg_agent_loop.ps1 `
  -MaxHours 5 -MaxRounds 20 -RoundTimeoutMinutes 45
```
