## 一、文档定位

项目实现两条算法路径，共享同一套数据和特征栈：

- **整体路**：`PhysicsResidualKernelRegressor`（`src/ml/universal_tg_model.py`），单一回归器，统一处理三任务。
- **路由路**：`UniversalTgRouter`（`scripts/predict_polymer_tg_universal.py`），按输入证据分发到 7 类路线和多个子方法。

两条路使用同一份均聚物 7,486 条 + 共聚物 149 条 + 核酸 17 条数据，共享 1191 维 `HYBRID-HOMO186` 特征空间，但叠加方式、训练目标、评估协议不同。

### 2.3 关键特征模块

#### VPD 虚拟聚合描述符（12 维，`src/features/virtual_polymerization.py`）

12 维 = Core 6 + Delta 4 + Junction 2：
- **Core (6)**：3-mer 寡聚体上的 `MolWt_per_RU`、`TPSA_per_RU`、`MolLogP_per_RU`、`HeavyAtom_per_RU`、`RotBonds_per_RU`、`RingCount_per_RU`（均除以 3）
- **Delta (4)**：`(dimer/2) - monomer` 的 MolWt/TPSA/LogP/RotBonds 差值（聚合效应）
- **Junction (2)**：`junction_hbond_count`（dummy 邻域 N/O 数）+ `junction_flex_ratio`（柔性非环单键占比）

寡聚体构建：解析 SMILES 中 2 个 `*` → 复制 n=3 份 → 副本间 `RWMol.AddBond(right_neighbor[i], left_neighbor[i+1])` → 移除 dummy → sanitize。

#### PHY-C 链段物理（PPF 10 + ChainPhysics 8 + Interchain 8 + GC_Tg 2，共 28 维新增）

**PPF 10 维（`src/features/physical_proxy.py`）**：
- 1. `M_per_f`：分子量 / 柔性键数（Schneider-DiMarzio M/f）
- 2. `CED_estimate`：凝聚能密度 = δ²
- 3. `Vf_estimate`：自由体积分数（3D vdW / GC V_m）
- 4. `backbone_rigidity`：刚性键占比（双键+芳香 / 总主链键）
- 5. `steric_volume`：侧链体积（侧链重原子 × 15 Ų）
- 6. `flexible_bond_density`：柔性键 / 重原子
- 7. `symmetry_index`：对称性 ∈ [0, 1]
- 8. `side_chain_ratio`：侧链原子 / 主链原子
- 9. `CED_hbond_frac`：H 键 CED 贡献 / 总 CED
- 10. `ring_strain_proxy`：3-4 元环 / 总环数

**柔性键计数规则（PMC2203329）**：仅计非环单键；末端原子(度=1)=0；酰胺 C-N=0；Si-O=1.5；芳基-芳基=0.5；C-C/C-O/C-N/C-S 非环=1.0；最小值=0.1。`is_terminal_substituent()` 用图直径找链端，区分真实末端 vs 骨链末端。

**ChainPhysics 8 维（`src/features/chain_physics.py`）— 3-mer 构象采样**：
- 1. `Neff_300K`：300K Boltzmann 等效构象数 = `1/Σ(p_i²)`
- 2. `Neff_500K`：500K 等效构象数
- 3. `Neff_ratio`：`Neff_500K / Neff_300K`（能量景观陡峭度）
- 4. `conf_strain`：`mean(E) - min(E)`，单位 kcal/mol
- 5. `Cn_proxy`：`<R²> / (n·l²)`，特征比
- 6. `curl_ratio`：端到端距离 / contour 长度
- 7. `curl_variance`：`std(R_ee) / mean(R_ee)`
- 8. `oligomer_level`：成功标记（0=失败 / 3=3-mer 成功）

构象采样流程：`build_oligomer(smiles, n=3)` → `AddHs` → `ETKDGv3 embedMultipleConfs(50)` → MMFF94 优化（200 迭代，超时控制应对 Si 挂起）→ Boltzmann 权重 `p_i = exp(-E_i·β) / Σ exp(...)`，β = 1/(R·T)，R = 0.001987 kcal/(mol·K)。

#### GC_Tg 基团贡献（2 维，`src/features/gc_tg.py`）

GC 公式（Cao 2020）：`Tg(∞) = 1000 × Σ(n_i · Y_gi) / Mw`，单位 K，`Y_gi` 单位 K·kg/mol。

24 个基团按优先级（大→小）匹配，覆盖率 < 30% 返回 NaN。校准过的关键 Y_g 值（变更以适配实测分布）：
- 酰胺 amide：42 → 25
- 硅氧烷 Si_diCH3：-5 → 6
- 氯 CHCl：12 → 19（高优先级解释 PVC 高 Tg）
- 主键 CH_CH3 (PP)：4.03 → 8.22

输出 2 维：`GC_Tg`（公式预测值）+ `GC_coverage`（基团覆盖率）。在 198 聚合物上 r = 0.554 with Tg。

#### HBond（slim 5 维 / full 15 维，`src/features/hbond_features.py`）

10 个 SMARTS 模式 + CED 值（J/cm³）：amide 1862, urea 2079, urethane 1385, imide 980, phosphoester 1000, aromatic_nh 600, benzimidazole 1200, pyrimidine 500, purine 800, hydroxyl 1500。

**5 维精简版（PHY-C 用，按 SHAP 重要性筛选）**：
1. `ced_weighted_sum`：CED × 计数加权和（SHAP 第 7 位，6.89 重要性）
2. `total_hbond_density`：(donors + acceptors) / 重原子
3. `hbond_network_potential`：(donors × acceptors) / 重原子²
4. `polar_fraction`：TPSA / (TPSA + 非极性 SA)
5. `interaction_types`：存在的 H 键基团类型数

#### GNN PhysicsGAT（64 维，`src/gnn/physics_gat.py`）

架构：
```
GATConv(25→128, heads=4) → BatchNorm → ELU
GATConv(128→128, heads=4) → BatchNorm → ELU
GATConv(128→64, heads=1) → ELU
RepeatInvariantPooling (GRIN 中间重复单元，max/mean/attention)
```

预训练数据：NeurIPS + PolyMetriX ~10-15K（**不含 unified_tg，零泄漏**）。

微调机制：在 Nested CV 每个 outer fold 内独立微调（outer=`RepeatedKFold(5,3)`，inner=`KFold(3)`），输出 64 维嵌入。

输入图节点：3-mer SMILES 的原子图（25 维节点特征）。

#### polyBERT PCA（64 维，`src/gnn/polybert_embedder.py`）

模型：DeBERTa-v2，Kuenneth & Ramprasad, *Nature Comm.* 14, 4099 (2023)。原始嵌入 600 维。

PCA 流程：
1. 在训练数据上 `PCA(n_components=64, random_state=42)` 拟合
2. 全量 `transform`
3. 解释方差 ~85%

#### Afsordeh（4 维，`src/features/afsordeh_features.py`）

来自 Afsordeh & Shirali 2025（论文宣称 R²=0.97 in 90/10 split + 12 测试样本）：
- `FlexibilityIndex` = `NumRotBonds / HeavyAtomCount`（**SHAP 第 1 位，41.51 重要性**）
- `HBondDensity` = `(HDonors + HAcceptors) / HeavyAtomCount`
- `PolarityIndex` = `(nO + nN + nS) / HeavyAtomCount`
- `SOL`：Hildebrand 溶解度（Van Krevelen GC）

### 2.4 共聚物特征聚合算法（`polymer_record_to_features`，`src/ml/universal_tg_features.py`）

输入：n 个组分 SMILES 及对应权重 w；每个组分调用 `compute_features` 得 1191 维向量 `v_i`。

聚合到统一表的 5 类列（每类 1191 维）：

| 列前缀 | 公式 | 物理意义 |
|---|---|---|
| `emb_mean_d` | `Σ w_i · v_i[d]` | 加权平均（端点 Tg 类似 Fox） |
| `emb_std_d` | `√(Σ w_i · (v_i[d] - mean)²)` | 加权标准差（混合不均匀度） |
| `emb_min_d` | `min_i(v_i[d])` | 逐维最小（短板效应） |
| `emb_max_d` | `max_i(v_i[d])` | 逐维最大（长板效应） |
| `emb_contrast_d` | `max - min` | 组分差异度 |

外加固定列（14 列）：`sample_id, source, architecture, n_components, w_max, w_min, w_entropy, w_herfindahl, w_sorted_1..5, is_homopolymer, is_random, is_block, is_multicomponent`。

端点统计列（9 列）：`endpoint_missing_count, endpoint_missing_fraction, endpoint_all_measured, endpoint_tg_{min, max, mean, weighted_mean, delta, fox}_c`。

`endpoint_tg_fox_c = 1 / Σ(w_i / Tg_i_K) - 273.15`（K 单位求和后转 °C）。

均聚物时 n=1，则 `emb_std/emb_contrast = 0`，`emb_min = emb_max = emb_mean = v_1`，`is_homopolymer = 1.0`。

`normalize_weights`：检查 1D / 非空 / 非负 → `w / Σw` 归一化为概率。

## 三、整体路：Universal Single Regressor

### 3.1 模型类总览

`PhysicsResidualKernelRegressor`（`src/ml/universal_tg_model.py:24-637`）由 6 个可装配的算法块组成。预测公式：

```
ŷ = prior(X)
  + (1 - α_local) · kernel_residual(X) + α_local · local_residual(X)
  + homo_correction(X)
ŷ = final_calibration(X, ŷ)
ŷ = final_shrinkage(X, ŷ)
```

`α_local = local_weight`，默认 0；exp56：0.15。

### 3.2 算法块逐一拆解

#### 3.2.1 prior（物理先验）

加权岭回归，仅用物理/组成列：

- 列匹配：`prior_column_patterns` 默认 `["endpoint_tg_", "w_", "n_components", "is_homopolymer", "is_random", "is_block", "is_multicomponent"]`。
- 设计矩阵：`X_p = [1, x_scaled[:, prior_indices]]`
- 解析解：`coef = (X_p^T W X_p + λI')^{-1} X_p^T W y`，`I'` 在第 0 行/列为 0（截距不惩罚）
- exp56：`λ_prior = 0.5`（默认 1.0）

#### 3.2.2 RBF kernel residual

**Landmarks 选择**（`_select_landmarks:535-546`）：从 `x_kernel` 行集合按 `sample_weight` 概率分布**无放回采样** `n_landmarks` 行。Sample size < n_landmarks 时取全部。

**Gamma 自适应**（`_median_gamma:548-561`）：
```
d2_pairs = pairwise_sq_dist(landmarks)[upper_triangle]
gamma   = 1 / (2 · median(d2_pairs))
```
若 landmarks > 512 抽 512 子集计算。

**RBF 特征**（`_rbf_features:563-586`）：
```
φ(x) = [exp(-γ · s · d²(x, L)) for s in kernel_scales]   # 横向拼接
d²(x, L) = ||x||² + ||L||² - 2 · x · L^T                  # 下界 0
```
`kernel_scales` 默认 `(1.0,)`，exp56 同。多 scale 时输出 `n × (n_landmarks · |scales|)`。

**Ridge 拟合**：`(φ^T W φ + λ_residual · I)^{-1} φ^T W (y - prior_pred)`。
exp56：`λ_residual = 2.0`（默认 3.0）。

**high_dim_kernel 权重**（`_kernel_feature_weights:416-434`）：对前缀 `emb_mean_/std_/min_/max_/contrast_` 的列，提取末尾维度 `d`，若 `high_dim_start ≤ d < high_dim_end` 则乘以 `high_dim_kernel_weight`。
exp56：`high_dim_start=46, high_dim_end=233, high_dim_kernel_weight=0.0`，即把 BestTg 186d 区间在主核中**完全禁用**（该区间留给 homo_correction 单独建模）。

**additive_kernel_groups**（`_fit_additive_groups:594-620`）：对每组列做独立 RBF 核，exp56 未启用（`additive_kernel_groups=()`）。

#### 3.2.3 homo_correction（均聚物专用高维残差）

仅用于 `is_homopolymer > 0.5` 的行，专门吸收 BestTg 186d 区间的非线性。

**拟合**（`_fit_homopolymer_correction:453-492`）：
1. 从 `is_homopolymer > 0.5` 的训练样本中按权重无放回采样 `homo_correction_landmarks` 行（exp56：1800，默认 800）
2. 切片到 `emb_*_46-232` 维（与 high_dim_kernel 区间重合）
3. 计算 `γ_homo`（同 `_median_gamma`）
4. 在该高维子空间上拟合 RBF：`φ_homo = exp(-γ_homo · d²(x_homo, L_homo))`
5. Ridge 解：`(φ_homo^T W φ_homo + λ_homo · I)^{-1} φ_homo^T W r`，其中 `r = y - prior - kernel_residual`
6. exp56：`λ_homo = 0.1`（默认 1.0）

**预测**（`_homopolymer_correction:494-506`）：
```
correction = (is_homopolymer > 0.5) · φ_homo(x) · coef_homo
```
非均聚物行 gate=0，校正不生效。

#### 3.2.4 local_residual（KNN 局部残差）

`_local_residual:622-636`。可选项，exp56 启用。

```
d² = pairwise_sq_dist(x_kernel_test, train_kernel_)
neighbors = argpartition(d², k)[:k]
scale = median(d²[d² > 1e-12])
w = exp(-d²[neighbors] / scale) · train_weights_[neighbors]
local_pred = Σ(w · train_residual_[neighbors]) / Σw
```

`train_residual_` 是训练阶段最终保留的残差。exp56：`local_k=8, local_weight=0.15`。

#### 3.2.5 final_calibration（最终校准）

设计矩阵（`_final_calibration_design:271-289`）：

```
Block 1:  常数 1
Block 2:  x_scaled[:, calibration_indices]                 # 可选
Block 3:  (base_pred - x_raw[:, pred_delta_ref])           # 可选，pred-delta
若 gate_column 指定:  以上 blocks 元素级乘以 gate(x_raw)
```

exp56 配置：
- `final_calibration_columns = ("endpoint_tg_fox_c",)` → Block 2 = 标准化的 Fox 端点 Tg
- `final_calibration_pred_delta_reference_column = "endpoint_tg_fox_c"` → Block 3 = `base_pred - fox_endpoint_c`（**模型预测与 Fox 物理基线的偏差**）
- `final_calibration_gate_column = "is_homopolymer"`，`gate_invert=True` → 仅对**非均聚物**生效
- `final_calibration_lambda = 0.1`

**核心物理含义**：在非均聚物上，根据 `(Fox 端点, 模型对 Fox 的偏离量)` 学一个低容量的二维线性校正，把模型预测向"既参考端点又不偏离 Fox 太多"的方向拉回。

**拟合**：
```
correction = (D^T W D + λ · I)^{-1} D^T W (y - base_pred)
```
其中 `D` 即上述设计矩阵。

#### 3.2.6 final_shrinkage（最终收缩）

`_apply_final_shrinkage:334-360`。在低 Fox 区域把预测值向 Fox 物理基线收缩。

```
若 gate 触发:
    out = ref + scale · (pred - ref)        # ref 为反缩放的 final_shrinkage_reference_column
否则:
    out = pred
```

exp56 配置：
- `final_shrinkage_reference_column = "endpoint_tg_fox_c"` → ref 是 Fox 端点 Tg
- `final_shrinkage_scale = 0.75` → 触发时收缩 25% 朝 ref
- `final_shrinkage_gate_column = "endpoint_tg_fox_c"`，`gate_threshold = -35.0`，`gate_less_than = True` → 仅当 `Fox < -35°C` 时触发
- `final_shrinkage_exclude_homopolymer = True` → 均聚物不参与收缩

物理动机：低 Tg 共聚物（Fox < -35°C）端点信号强但模型容易外推过头，向 Fox 基线收缩降低误差。

### 3.3 fit / predict 完整伪代码

```python
def fit(X, y, sample_weight):
    # 1. 数据规范
    x_raw, names = _as_matrix_and_names(X)
    weights = _normalise_sample_weight(sample_weight)        # w / mean(w)
    
    # 2. 加权插补与标准化
    impute_values_ = _weighted_nanmedian(x_raw, weights)
    x_imputed = x_raw.copy(); x_imputed[NaN] = impute_values_
    x_mean_, x_scale_ = weighted_mean_var(x_imputed, weights)
    x_scaled = (x_imputed - x_mean_) / x_scale_
    
    # 3. 高维 kernel 权重
    kernel_feature_weights_ = _kernel_feature_weights(names)
    x_kernel = x_scaled * kernel_feature_weights_
    
    # 4. 物理先验
    prior_indices_ = _select_prior_indices(names)
    prior_design = [1, x_scaled[:, prior_indices_]]
    prior_coef_ = ridge(prior_design, y, weights, λ_prior, no_penalty_intercept=True)
    prior_pred = prior_design @ prior_coef_
    residual = y - prior_pred
    
    # 5. RBF 主核
    landmark_idx = _select_landmarks(x_kernel, weights, n_landmarks)
    landmarks_ = x_kernel[landmark_idx]
    gamma_ = _median_gamma(landmarks_)
    _fit_additive_groups(...)                                # exp56 跳过
    phi = _rbf_features(x_kernel)
    residual_coef_ = ridge(phi, residual, weights, λ_residual)
    
    # 6. 保留训练核矩阵（local_residual 用）
    train_kernel_ = x_kernel
    train_residual_ = residual - phi @ residual_coef_
    train_weights_ = weights
    
    # 7. 均聚物高维校正
    base_pred_train = prior_pred + phi @ residual_coef_
    _fit_homopolymer_correction(x_scaled, y - base_pred_train, weights, names)
    
    # 8. 最终校准（在 base_pred + homo_correction 后拟合）
    uncal_train_pred = _predict_uncalibrated(x_scaled, x_kernel)
    _fit_final_calibration(x_scaled, uncal_train_pred, y, weights, names)
    
    # 9. 最终收缩参数（无拟合，仅记录配置）
    return self


def predict(X):
    x_imputed = impute(X, impute_values_)
    x_scaled = (x_imputed - x_mean_) / x_scale_
    x_kernel = x_scaled * kernel_feature_weights_
    
    prior = _prior_design(x_scaled) @ prior_coef_
    kernel_res = _rbf_features(x_kernel) @ residual_coef_
    
    if local_k > 0:
        local_res = _local_residual(x_kernel)
        out = prior + (1 - local_weight) * kernel_res + local_weight * local_res
    else:
        out = prior + kernel_res
    
    out += _homopolymer_correction(x_scaled)
    out  = _apply_final_calibration(x_scaled, out)
    out  = _apply_final_shrinkage(x_scaled, out)
    return out
```

#### 4.2.1 BestTgPredictor 186d TabPFN（`scripts/predict_tg_tabpfn_186d.py`）

**特征装配** `featurize_component:532-570`，三级缓存命中：

**fit** `:370-424`：

#### 4.2.2 Fox 公式（`src/ml/copolymer_physics.py::fox_tg_k:29-37`）

```
Tg_mix_K = 1 / Σ(w_i / Tg_i_K)
约束: 所有 Tg_i > 0, w_i ≥ 0, Σw_i > 0

```

#### 4.2.3 global Linear-Fox（`UniversalTgRouter._fit_global_linear_model:178-202`）

```
X = (calibration["fox_endpoint_tg_c"] + 273.15).reshape(-1, 1)   # K
y = calibration["Tg_C"]               + 273.15                    # K
model = RidgeCV(alphas=np.logspace(-6, 4, 24)).fit(X, y)
```

#### 4.2.4 same-system residual IDW（`UniversalTgRouter._local_residual_correction:283-332`）

输入 `match.rows`（同体系或同组分对的 PolyInfo 行）、查询 w1、基础预测 `query_base_c`。

```
1. 计算训练行的基础预测
   base_train_K = global_linear_model.predict(rows["fox_endpoint_tg_c"] + 273.15)
   residual_C   = rows["Tg_C"] - (base_train_K - 273.15)

2. 距离: distance = |rows["w1_used"] - query_w1|

3. 精确匹配优先
   if any(distance < 1e-12):
       correction_C = mean(residual_C[exact])
   else:
       order   = argsort(distance)[:k]
       w_idw   = 1 / (distance[order]^power + 1e-9)
       correction_C = Σ(w_idw · residual_C[order]) / Σ(w_idw)

4. tg_c_pred = query_base_c + correction_C
```

默认 `k = local_k = 3`，`power = local_power = 1.0`，`min_local_points = 2`。

`_calibration_match` 双向匹配：先按 `(canonical_1, canonical_2)` 顺序匹配，再按交换方向匹配（`query_w1_used = 1 - w1_used`）；若有 `system_id` 命中则优先 `system_id_component_pair` 类匹配，否则 `component_pair` 类。

**leave-composition mode**：评估时启用 `local_calibration_mode="leave-composition"`，剔除 `|w_train - w_query| < 1e-6` 的同组成行。

#### 4.2.5 共聚物物理基线 `evaluate_polyinfo_copolymer_physics.py`

**Fox 预测**（`_fox_prediction_for_orientation:100-114`）：直接用 `fox_tg_k`。

**Linear-Fox CV**（`_linear_fox_cv_predictions:336-351`）：以 `[[fox_k]]` 为单变量做 RidgeCV(α∈[1e-6, 1e4], 24 个值)。LOOCV 或 leave-group-out 模式。

**Physics-Ridge**（`_ridge_features:263-284 + _ridge_cv_predictions:300-316`）：
```
X = [fox_k, w1, w2, w2², w1·w2, Tg2_K - Tg1_K, category_interaction[*]]
   shape = (n, 5 + n_categories)
ridge.fit(X, Tg_K)  with alphas ∈ [1e-4, 1e4], 30 values
```
`category_interaction = w1·w2` 当 row 的 category 等于该列对应 label，否则 0（用于 PolyInfo 的体系类别交互）。

**Kwei**（`copolymer_physics.py::kwei_binary_tg_k:49-53 + fit_kwei_k_q:94-119`）：
```
GT(w1,w2,k) = (w1·Tg1 + k·w2·Tg2) / (w1 + k·w2)              # Gordon-Taylor
Kwei:        Tg = GT(w1,w2,k) + q·w1·(1 - w1)

拟合:
  for k in linspace(0.2, 5.0, 481):
      q_opt = Σ(interaction · (y - GT)) / Σ(interaction²)
      MSE   = Σ((y - GT - q · interaction)²)
  选 (k*, q*) 最小化 MSE
LOOCV: _loocv_kwei:226-235，逐点留一拟合
```

## 附录 A：关键公式速查

```
Fox 公式 (K):                Tg = 1 / Σ(w_i / Tg_i)
Gordon-Taylor (K):           Tg = (w1·Tg1 + k·w2·Tg2) / (w1 + k·w2)
Kwei (K):                    Tg = GT(w1, w2, k) + q · w1 · (1 - w1)
Linear-Fox (K):              Tg = RidgeCV([[fox_k_i]], Tg_i)
Physics-Ridge (K):           Tg = Ridge([fox_k, w1, w2, w2², w1·w2, ΔTg, cat_int], Tg_i)
GC_Tg (K):                   Tg = 1000 · Σ(n_i · Y_gi) / Mw

加权 Ridge:                   coef = (X^T W X + λ I)^(-1) X^T W y    [I[0,0]=0 不惩罚截距]
RBF kernel:                   φ(x, L)_j = exp(-γ · ||x - L_j||²)
γ 自适应:                     γ = 1 / (2 · median(pairwise_d²(L)))
IDW 残差:                     correction = Σ(1/d_i^p · r_i) / Σ(1/d_i^p)
KNN 局部残差:                 local = Σ(exp(-d²/scale)·w_i·r_i) / Σ(...)
final_shrinkage:             out = ref + scale · (pred - ref)        if gate(x)
final_calibration (pred-delta): correction = Ridge(D, y - base_pred), D 含 (base_pred - x[ref])

共聚物特征聚合 (5 类 × 1191 维):
  emb_mean_d  = Σ w_i · v_i[d]
  emb_std_d   = √(Σ w_i · (v_i[d] - mean_d)²)
  emb_min_d   = min_i v_i[d]
  emb_max_d   = max_i v_i[d]
  emb_contrast_d = max - min

构象 Boltzmann 权重 (3-mer):  p_i = exp(-E_i β) / Σ exp(-E_j β),  β = 1/(R T), R = 0.001987 kcal/(mol·K)
Neff:                         N_eff = 1 / Σ(p_i²)
```
